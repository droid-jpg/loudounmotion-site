# Archived design: v1 "Production Script" (Nov 25, 2026)

The first full loudounmotion.com design, retired the same day for a calmer, simpler site.

- Concept: the page read as a timecoded Video | Audio production script, with a live REC readout,
  a sample script for a made-up café you could play in real time, and a night end card with a quote form.
- Live code: `index.html` and `assets/` on this branch, exactly as shipped (commit c53158f on main).
- Screenshots: `v1-desktop.png` (1440 wide) and `v1-mobile.png` (390 wide), full page.
- Design system record: `v1-DESIGN.md`.

To preview it locally: check out this branch and open `index.html`, or run `python3 -m http.server` in the repo.
